Post Mortem

Inspiration

  • U Gears Model Train
  • Derail Valley Game Loop

Initial Goal

  • Simple structure, least amount of extra rules necessary
  • Contemporary modern setting
  • Focus on core game rules
    • Gauge user friendliness of char sheet
    • See adoptability of first time players

Adventure Premise and Structure

  • go to a small depot of sorts to retrieve an old modified steam locomotive
  • navigate the derelict track network
  • move the train into a museum

Prepared Props

  • char sheet (duh)
  • train cab hand sketch
  • actual cab footage?
  • track map with dm version

Prepared Characters

  • 5 Characters, for each player 1 (two chars were unused)
    • Nerd Cantila Gilstando -> Garnella Clizreubo
    • Rockstar Frederick 'Fallen Star' Falster -> Fliederick Walter
    • Sporty Athlete Jill Hellberne -> Bill Hellburn

Original Story

  • Museum director needed this train to be moved discreetly

  • He contact some mercenaries online (deep web)

  • Mercenaries use encrypted address codes instead of normal addresses

    • Director writes the codes -> does it badly -> address codes changed, mail gets sent to wrong addresses
    • Uses custom altered playing cards with fluorescent stuff

  • Director had wrong people, wrong names and used wrong names for each pc, and refused to change

  • Director move players via jeep to depot location

  • Players try to figure out opening the depot

  • Players try to jumpstart the loco

  • Players had to navigate the track net

  • Players go to museum

What went well

  • reveal of train model
  • character sheets were adequately usable
  • everyone had fun
  • improvisation went surprisingly well
  • vitality system

What went badly

  • the network part
  • time, so much lost time (original plan 5 to 6 hours, it was about 12h)
    • how much longer would it take with 5 players?
    • character creation would take up a lot of time as well
  • bandits were defeated too easily - fight was underwhelming
    • need to adjust action economy
  • navigation was not covneyed effectively
  • not enough plan Bs
  • BETTER FUCKING INTROS

What can be learned

  • better time planning: much shorter adventure, focus on character play rather than story
  • play around with action point amounts, maybe 2 ap per round works better
    • maybe the cogent initiative? needs adapting. core idea might work
  • no magic inventions without outright telling players how to operate them if expected to handle
  • get better at making plan Bs. skill issue
  • make intros shorter, and actually plan them out. intros are the tutorials of story games.
